# 3. Общий скилл shadcn-collector

> **Статус:** ✅ работает
> **Зависимости:** [02-native-host](02-native-host.md) (источник пакетов `Collector/<id>/`)

## Назначение

Скилл для кодирующих агентов (Codex, Claude Code), который резолвит собранный
пакет и реализует страницу или блок. Канонический источник —
`skills/shadcn-collector/` в этом репозитории; ставится в глобальные каталоги
скиллов обоих агентов.

## Архитектура

- `skills/shadcn-collector/SKILL.md` — единственный файл скилла.
- Детерминированный резолвер принимает ровно шесть цифр и ищет
  `Collector/<id>/` в текущем каталоге и родительских; валидирует
  `page-spec.json` до того, как агент начинает читать или реализовывать пакет.
- Два режима по формату входа: **A** — номер пакета (`Collector/<id>/`),
  **B** — вставленный JSON `kind: "single-block"` (ничего не пишет на диск).

## API / Интерфейс

Не HTTP — вызывается агентом по триггерам `$shadcn-collector <id>`,
`/shadcn-collector <id>`, `Collector <id>`, либо по вставленному payload.

## Данные

Читает файлы, созданные Native Host: `page-spec.json`, `PAGE_SPEC.md`, PNG.
Ничего не пишет обратно в `Collector/`.

## Конфигурация

`COLLECTOR_SKILL_NAME`, `CODEX_SKILLS_DIRECTORY`, `CLAUDE_SKILLS_DIRECTORY` —
из `.env`, используются установщиком (`scripts/install-host.mjs`), не самим
скиллом.
