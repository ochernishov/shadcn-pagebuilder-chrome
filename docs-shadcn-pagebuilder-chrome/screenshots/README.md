# Скриншоты документации

Скриншоты не образуют отдельную галерею: используемые изображения встроены непосредственно в соответствующие разделы корневого [`README.md`](../../README.md). Актуальная привязка файлов и статус публикации хранятся в [`images.manifest.json`](images.manifest.json).

## Правила публикации

- Формат — JPEG с расширением `.jpg`.
- Локальные пути и папки Finder допускаются по прямому решению владельца репозитория; секреты, токены и закрытые данные по-прежнему запрещены.
- Публичное превью платной библиотеки допустимо, если на скриншоте нет закрытого исходного кода.
- Неиспользуемые исходные снимки остаются локальными и не должны попадать в публичный коммит без обезличивания.

## Текущее состояние

- В README встроено 12 скриншотов.
- Снимок запроса разрешения отсутствует и больше не требуется.
- `02-project-settings-expanded.jpg`, `03-project-folder-picker.jpg` и `11-finish-page.jpg` публикуются как есть по решению владельца репозитория.
- Локальный `05-chrome-shortcut-settings - 1.jpg` не публикуется и не входит в публичный манифест, потому что постороннее предупреждение Chrome может быть ошибочно связано с Collector.
- Для настройки сочетания клавиш используется `05-chrome-shortcut-settings - 2.jpg`.
