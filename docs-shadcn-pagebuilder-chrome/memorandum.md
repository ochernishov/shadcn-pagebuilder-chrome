# Меморандум — Shadcn Page Collector

## Что за проект

Chrome-расширение (Manifest V3) для сбора визуальных референсов (блоков,
скриншотов, текста) с любых сайтов и передачи их кодирующему агенту (Codex,
Claude Code) как локальный пронумерованный пакет `Collector/<id>/`. Расширение
не решает, что можно устанавливать — оно фиксирует только то, что пользователь
уже видит на экране, и не обходит подписки, аутентификацию, пейволлы или
лицензионные ограничения.

## Для кого

Разработчики, использующие Codex или Claude Code для реализации UI на основе
компонентных библиотек (в том числе платных, вроде Shadcn Blocks) и обычных
сайтов-референсов. Инструмент личного/командного использования разработчика,
не SaaS для конечных клиентов.

## Заказчик

Проект COS (Олег Чернышов), публичный open-source репозиторий
(`github.com/ochernishov/shadcn-pagebuilder-chrome`, лицензия MIT).
